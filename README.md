# Эмулятор CHIP-8

Это легковесный эмулятор виртуальной машины CHIP-8, написанный на современном C++ без использования прямого управления памятью.

## Руководство пользователя

### Назначение программы
Программа принимает на вход скомпилированные ROM-файлы (игры или программы) архитектуры CHIP-8, загружает их в виртуальную память и исполняет заложенные в них инструкции процессора.

### Установка и запуск
Проект собирается с помощью CMake. В качестве операционной системы рекомендуется использовать Linux (например, Fedora).

1. Установите необходимые зависимости сборки. Пример для Fedora:
   `sudo dnf install gcc-c++ cmake git doxygen clang-tools-extra`
2. Склонируйте репозиторий и перейдите в папку:
   `git clone <url-вашего-репозитория> chip8`
   `cd chip8`
3. Выполните сборку:
   `mkdir build && cd build`
   `cmake ..`
   `cmake --build .`
4. Запустите эмулятор, передав путь к ROM файлу (используйте прямые слеши `/`):
   `./chip8_emu ../roms/ibm_logo.ch8`

### Обработка ошибок
Программа безопасна: если вы передадите некорректный путь или программа наткнётся на битый файл, она выдаст понятное исключение и корректно завершит работу без утечек памяти.

## Руководство разработчика

### Организация репозитория
Разработка ведётся по схеме:
- Ветка `dev` является основной веткой разработки.
- Для каждого нового функционала создаётся ветка от `dev` (например, `feature/graphics`).
- При завершении функционала делается Merge-запрос обратно в `dev`.

### Тесты
Проект покрыт unit-тестами с использованием Doctest. Для запуска тестов выполните:
`cd build`
`ctest --output-on-failure`

### Документация (Doxygen)
Документация к коду автоматически генерируется CMake в папку `build/docs/html`. Откройте файл `index.html` в вашем браузере для просмотра описания всех классов и функций.

### Стиль кода
Все исходные файлы проверяются утилитой `clang-format` на соответствие стилю Google.
